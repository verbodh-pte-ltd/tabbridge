Connect an agent

Install the host once, then add TabBridge to your agent:

npx tabbridge install

claude mcp add tabbridge -- npx -y tabbridge mcp

For Codex, Gemini CLI, Cursor and others run npx tabbridge config codex (or gemini, cursor, json).
